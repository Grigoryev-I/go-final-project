# Планировщик задач

## Описание проекта

Учебный проект: веб-сервер на Go, реализующий бэкенд «Планировщика задач» (TODO-листа).
Сервер отдаёт готовый фронтенд, хранит задачи в базе данных SQLite
и предоставляет REST API для создания, чтения, изменения и удаления задач, отметки их
выполненными и для расчёта следующей даты по правилам повторения.

## REST API

| Метод  | Путь                              | Назначение                          |
|--------|-----------------------------------|-------------------------------------|
| GET    | `/api/nextdate?now=&date=&repeat=`| следующая дата по правилу повторения|
| GET    | `/api/tasks?search=`              | список ближайших задач (до 50)      |
| POST   | `/api/task`                       | добавить задачу                     |
| GET    | `/api/task?id=`                   | получить одну задачу                |
| PUT    | `/api/task`                       | изменить задачу                     |
| DELETE | `/api/task?id=`                   | удалить задачу                      |
| POST   | `/api/task/done?id=`              | отметить задачу выполненной         |

## Стек

- Go, пакет `net/http`;
- SQLite через `modernc.org/sqlite`;
- готовый фронтенд в директории `web` (index.html, css, js)

## Запуск локально

Требуется установленный Go. Запускать из корня проекта.

    go run main.go

**Адрес в браузере: http://localhost:7540/**

Переменные окружения (все необязательные):

## Запуск тестов

Тесты проверяют API по HTTP на `http://localhost:<Port>`, поэтому сначала запустите сервер
из корня проекта, а тесты выполняйте во втором терминале.

    # терминал 1
    go run main.go

    # терминал 2
    go test ./tests

Параметры в `tests/settings.go`:

| Параметр        | Значение                | Назначение                                       |
|-----------------|-------------------------|--------------------------------------------------|
| `Port`          | `7540`                  | порт, который слушает сервер                      |
| `DBFile`        | `../scheduler.db`       | путь к БД         |
| `FullNextDate`  | `true`                  | включает тесты правил `w`/`m`                     |
| `Search`        | `true`                  | включает тесты поиска `?search=`                  |
| `Token`         | ``                      | токен аутентификации (не реализовано)            |

## Сборка и запуск через Docker

    # 1. Собрать образ (из корня проекта)
    docker build -t planner .

    # 2. Запустить контейнер: публикуем порт и подключаем БД на хосте
    docker run -d --name planner -p 7540:7540 \
      -v "$(pwd)/data:/app/data" planner

**Адрес в браузере: http://localhost:7540/**

Windows (PowerShell):

    docker build -t planner .
    docker run -d --name planner -p 7540:7540 -v "${PWD}/data:/app/data" planner
